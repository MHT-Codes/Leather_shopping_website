ATELIER HIDE — HANDMADE LEATHER SHOWCASE

FILES
- index.html: page structure and content
- styles.css: responsive layout and visual design
- script.js: filters, search, favorites, customization and shopping bag
- JPG photos: stored beside the three code files in this folder

PREVIEW
Open index.html in a browser. The product and workshop photos are included locally. Google Fonts load online when available, with system font fallbacks.

GITHUB PAGES
Upload index.html, styles.css, script.js, README.txt and every JPG photo together into the same publishing folder (usually the repository root). Do not put the photos into a subfolder unless you also change their paths in index.html and script.js.

EDITING
Edit the products array near the top of script.js to change product names, descriptions, categories and prices. Replace the JPG photos with your own product photos using the same filenames.

This is a frontend showcase. It does not process payments or save newsletter signups to a server. Sample photos are from Unsplash; replace them with your own product photos before using the site as a real shop.
